{%- comment -%} Responsive photo: a with a WebP source and a JPEG fallback, each carrying a srcset assembled from the derivatives in assets/img/. Derivatives come from tools/build-images.sh, which crops every master in _photos-src/ to the aspect ratio of the slot it renders in. That crop is what makes the `w` descriptors below trustworthy: the image and its CSS box share an aspect ratio, so the width the browser picks is the width it paints. Note that .plate and .bs-arch absolutely position their image, so the CSS in assets/css/main.css matches `> picture > img` as well as `> img`. Adding a wrapper without that selector would drop object-fit and break the layout.
